# Dungeon
PLATO's "The Dungeon" aka pedit5 exact dungeon crawling experience recreation

# Features
 - Exact pedit5 dungeon layout
 - Hiding secret doors with 1/6 chance
 - Rendering logic like in original game
 - Dungeon navigation with arrow keys, breaking into doors with 'b'
